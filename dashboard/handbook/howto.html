Everyday recipes

Save a memory

You rarely do this by hand, your agents call remember when they learn something worth keeping. If you want to add something yourself, just tell your agent in plain language: "remember: the NAS backup runs every night at 3 AM". Specify privacy when it matters: "remember privately: …"

Find something again

Ask your agent, it calls recall with your question. You can also search the Inspector on the dashboard. Search works by meaning, so describe what you want, not exact words. Explicit searches see everything; the automatic pre-fetch (before each conversation turn) shows only memories your agent is allowed to see.

Update something that changed

Don't delete and re-save, just tell your agent the new truth. Nexus marks the old fact as superseded and links the new one as current truth. History stays intact, nothing is lost, and contradictions resolve themselves.

Back up everything

Click 📥 Backup in the dashboard. The backup contains every memory, including private ones, in one file with restrictive permissions. Keep it on another disk. Restoring is a single import: the backup file is fully self-contained.

How often? A weekly backup is plenty for most people. Before big experiments or updates: one extra click, zero regrets.

Update Nexus Memory

Updates arrive the same way your agents manage other tools. After an update the dashboard opens automatically so you can see the new state ("success moment"). Your memories are never touched by an update, the brain survives, only the software around it gets better.

Something looks wrong

  • Health dot is yellow/red: click ❤️ Health for the specific part that isn't answering.
  • Memories count dropped: check whether SICA cleaned expired temp/session entries (normal), then restore from your latest backup if real content is missing.
  • Agent doesn't remember: check it's connected (🔍 Detect Agents), then search the Inspector directly, if the memory exists, the agent's access level may be the limit.
  • Nothing is being sorted (Fuel idle): if the Fuel switch is OFF or no station is reachable, that's by design, flip the switch or provide Ollama/a key. Sorting is convenience, never a requirement.

Start fresh on a new machine

Install Nexus Memory, then import your backup file, everything comes back: memories, access levels, private entries. The archive travels; the agents reconnect automatically via 🔍 Detect Agents.
