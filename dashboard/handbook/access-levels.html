Who can see what, Access Levels

Every memory carries one of three visibility levels. This is the privacy backbone of Nexus:

LevelMeaningTypical content
🌐 publicevery connected agent can see itgeneral knowledge, project facts, how-tos
🔐 trustedonly agents you marked as trustedinternal team knowledge, personal workflows
🔑 privateonly you / explicitly permitted agentsfamily, finances, passwords, anything sensitive

How does Nexus "know" something is private?

It doesn't guess, you (or your agent) decide at save time. Every memory is stored with its access level as an explicit label. Rules of the road:

  • If nothing is specified, memories are saved as public, so treat "unlabeled" as "visible to all my agents".
  • Nexus helps you: it automatically detects patterns like e-mail addresses and phone numbers in a memory and then warns: "this looks sensitive, consider private."
  • When facts get merged or summarized later, they inherit the strictest level involved, consolidation can never degrade a private memory into something more visible.
  • If a memory has an unknown or missing level, it is treated as private (fail-closed), never as public.

Rules that protect you automatically

  • Supersession never crosses boundaries: a public fact can never overwrite a private one. Newer is not automatically stronger, stricter visibility wins.
  • Guardrail overrides (bypasses) are stored privately and are excluded from any summarization, the reasoning behind an override never leaks into distilled facts.
  • Backups include private memories and are therefore written with restrictive file permissions (private folder, owner-only files).

Practical advice

Rule of thumb: if a memory would bother you being read by a stranger looking at your screen, make it private. If it should be shared knowledge among your own machines but isn't for outsiders, trusted. Everything else: public.
Never store passwords or API keys in Nexus, even as private. Memory is for knowledge, not for credentials, use your system's keychain for secrets.

What "public" means, and what it doesn't

"Public" does not mean "on the internet". It means: visible to all agents connected to your Nexus instance. Nothing is ever sent to Nexus developers or third parties, the levels govern access between your own agents, nothing else.
